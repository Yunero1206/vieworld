## 🌟 Giới Thiệu Dự Án (Overview & Vision)

**VieWorld** là một nguyên mẫu sản phẩm quan hệ người hâm mộ di động (*portable fan relationship platform*) do **Phạm Thanh Phú** nghiên cứu và phát triển. Dự án giải quyết các vấn đề phân mảnh, thiếu tin cậy và thương mại hóa thái quá trong các mô hình fandom truyền thống bằng cách thiết lập một không gian kỹ thuật số minh bạch, nơi người hâm mộ thực sự sở hữu các kỷ niệm và giá trị gắn bó cùng nghệ sĩ yêu thích.

### 🔄 The Signature Loop (Vòng lặp trải nghiệm cốt lõi)

```text
Khám phá (Discover) 
    ↳ Vào thế giới nghệ sĩ (Enter World) 
        ↳ Theo dõi / Đăng ký (Follow / RSVP) 
            ↳ Tham gia tương tác trực tiếp (Participate) 
                ↳ Lưu trữ Moment Capsule 
                    ↳ Không gian cá nhân (My World / My Space) 
                        ↳ Sở hữu & Phục hồi kỷ niệm 
                            ↳ Quay lại khoảnh khắc kế tiếp (Return)
```

## 🚀 Các Tính Năng Nổi Bật (Core Highlights)

### 1. 🎤 Artist Home (Chuẩn Weverse / Fandom Hiện Đại)
- **Spotlight Hero Billboard:** Banner visual sân khấu ấn tượng với hiệu ứng ánh sáng sống động.
- **Story Ring Rail:** Vòng tròn cập nhật khoảnh khắc mới nhất của nghệ sĩ (Artist A, MIRA, Neon Sessions).
- **Bento Activity Hub:** Lối tắt nhanh vào Lịch trình biểu diễn, Phòng Live & Concert, Cộng đồng Hall và Cửa hàng VieSHOP.
- **Fandom Cover Cards:** Thẻ đại diện fandom độc đáo cho từng nghệ sĩ với số ngày gắn bó và các cột mốc fandom.

### 2. 💬 Moments & Live Chat Đa Chiều
- **Stage Phát sóng Chân thực (Honest Presence):** Phản ánh chính xác trạng thái online/offline của host. Tuyệt đối không dùng AI đóng giả nghệ sĩ.
- **Phòng Live Chat Đồng Bộ:** Hỗ trợ bình luận, gửi phản ứng cảm xúc (reactions) và ghim tin nhắn.
- **YouTube-Style Live Poll Overlay:** Hiển thị bình chọn trực tiếp nổi trên khung phát sóng dạng overlay tinh gọn, không chiếm không gian hay làm tụt luồng chat chính.
- **Lưu trữ Moment Capsules:** Đóng gói khoảnh khắc đáng nhớ vào bộ sưu tập cá nhân kèm ghi chú riêng tư.

### 3. 🏠 My Space & Fan Room (Diorama 2.5D Cá Nhân Hóa)
- **Phòng trưng bày 5 kệ chuyên biệt (Display Fixtures):**
  1. *Áo merch / Đồng phục fandom*
  2. *Vé concert kỉ niệm*
  3. *Đĩa CD / Album vật lý*
  4. *Lightstick phát sáng*
  5. *Huy hiệu thành tích / Chứng nhận đồng hành*
- **Tủ đồ Chibi (Wardrobe) & Trình thử trang phục:** Tự do tùy biến diện mạo đại diện chibi với các phụ kiện độc đáo.
- **Visitor Identity Preview:** Trang hồ sơ công khai thể hiện tâm trạng, huy hiệu và bộ sưu tập fan chân chính.

### 4. 🛍️ VieSHOP — Thương Mại Ngữ Cảnh (Contextual Commerce)
- **Minh bạch tuyệt đối:** Tách bạch giữa Theo dõi (Follow), Thành viên (Membership), Quyền lợi (Benefit) và Hàng hóa (Merchandise).
- **Luồng đơn hàng mô phỏng đa bước (Idempotent Orders):** Khởi tạo giỏ đồ → Xác nhận thanh toán an toàn → Đóng gói sản phẩm → Bàn giao đơn vị vận chuyển → Trung tâm phân loại → Giao hàng thành công.
- **Bảo mật & Không thu thập thẻ thật:** Mọi giao dịch đều là giả lập an toàn phục vụ kiểm thử luồng sản phẩm.

### 5. 🛡️ Hiến Pháp Sản Phẩm & Tính Chân Thực (`CONSTITUTION.md`)
- Duy trì huy hiệu `DEMO` minh bạch xuyên suốt hệ thống.
- Nhân vật & sự kiện hoàn toàn mang tính minh họa giả lập (`Artist A`, `Neon Sessions`, `MIRA`).
- Khả năng cách ly dữ liệu nhiều người thuê (*Multi-tenant Isolation: VieWorld, MFan, FanMe*) và cơ chế khôi phục lỗi toàn diện.

## 💻 Cài Đặt & Chạy Cục Bộ (Getting Started)

### Yêu cầu môi trường:
- **Node.js:** `>= 18.x` (khuyến nghị Node 20 LTS hoặc Node 22)
- **npm:** `>= 9.x`

### Các bước cài đặt:

```bash
# 1. Clone repository
git clone https://github.com/Yunero1206/vieworld.git
cd vieworld

# 2. Cài đặt các thư viện phụ thuộc
npm install

# 3. Khởi chạy máy chủ phát triển
npm run dev
# Mặc định truy cập tại: http://localhost:5173

# 4. Kiểm tra TypeScript & Chạy toàn bộ Test Suite
npm run typecheck
npm run test

# 5. Đóng gói bản Production
npm run build

# 6. Chạy thử bản Build (Preview)
npm run preview
# hoặc
npm start
```

## 🌐 Hướng Dẫn Triển Khai Lên Render (Deployment on Render)

Repository này đã được cấu hình tối ưu sẵn để triển khai trực tiếp lên **[Render](https://render.com/)**. Bạn có thể chọn 1 trong 2 phương thức dưới đây tùy theo nhu cầu:

---

### 👉 Cách 1: Triển Khai dạng "Static Site" (Khuyên dùng nhất - Nhanh, Ổn Định & Miễn Phí 100%)

Do VieWorld là ứng dụng Single Page Application (React + Vite), việc triển khai dạng **Static Site** trên Render đem lại hiệu năng CDN toàn cầu nhanh nhất, không bị giới hạn bộ nhớ hay rơi vào trạng thái ngủ đông (spin down).

#### Các bước cài đặt trên Render Dashboard:
1. Đăng nhập vào [Render Dashboard](https://dashboard.render.com/) và chọn **New +** ➔ **Static Site**.
2. Kết nối tới kho lưu trữ GitHub: `Yunero1206/vieworld`.
3. Điền các thông số cấu hình như sau:
   - **Name:** `vieworld` (hoặc tên tùy thích)
   - **Branch:** `main`
   - **Root Directory:** *(để trống)*
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist`
4. **Cấu hình định tuyến Single Page Application (BẮT BUỘC để tránh lỗi 404 khi chuyển trang):**
   - Kéo xuống mục **Redirects/Rewrites**, nhấn **Add Rule**:
     - **Type:** `Rewrite`
     - **Source:** `/*`
     - **Destination:** `/index.html`
     - **Action:** `Save Changes`
5. Nhấn **Create Static Site** và chờ Render hoàn tất build!

---

### 👉 Cách 2: Triển Khai dạng "Web Service" (Theo đúng yêu cầu của bạn)

Nếu bạn muốn deploy trực tiếp bằng loại dịch vụ **Web Service** (Node.js runtime có server lắng nghe cổng `$PORT`):

Dự án đã được cấu hình sẵn file [`vite.config.ts`](./vite.config.ts) để tự động lắng nghe cổng môi trường `$PORT` do Render chỉ định trên host `0.0.0.0` cùng tính năng `allowedHosts: true`.

#### Các bước cấu hình Web Service trên Render:
1. Tại Render Dashboard, chọn **New +** ➔ **Web Service**.
2. Kết nối tới repo: `Yunero1206/vieworld`.
3. Nhập các thông số sau:
   - **Name:** `vieworld-web`
   - **Region:** Singapore (Southeast Asia) hoặc bất kỳ
   - **Branch:** `main`
   - **Root Directory:** *(để trống)*
   - **Runtime:** `Node`
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
4. **Biến môi trường (Environment Variables - Khuyến nghị):**
   - `NODE_VERSION`: `20.18.0` (hoặc `22`)
5. Nhấn **Create Web Service**. Render sẽ tự động build dist và khởi chạy web service với lệnh `npm start`.

---

### 👉 Cách 3: Sử Dụng Render Blueprint (`render.yaml`)

Trong mã nguồn đã tích hợp sẵn file [`render.yaml`](./render.yaml). Bạn chỉ cần:
1. Vào Render Dashboard ➔ Chọn **Blueprints** ➔ **New Blueprint Instance**.
2. Kết nối tới repo `Yunero1206/vieworld`.
3. Render sẽ tự động nhận diện toàn bộ thiết lập cấu hình và khởi tạo dịch vụ chỉ với 1 cú click chuột!
