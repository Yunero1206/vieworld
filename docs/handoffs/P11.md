- Implemented pure avatar reducers in `src/domain/reducer.ts`:
  - `SAVE_AVATAR_DRAFT`: Persists working draft asset without modifying the world's active avatar (`world.avatarAssetId`).
  - `APPROVE_AVATAR_ASSET`: Promotes draft asset to `approved`, generates synthetic `approvalRef: APPROVAL-SIM-2026-XXXX`, updates world's active avatar.
  - `RETIRE_AVATAR_ASSET`: Marks asset as `retired`, permanently preventing new session starts or assignments.
  - `REVERT_AVATAR_VERSION`: Allows activating a previously approved version for a world.
  - `ASSIGN_AVATAR_TO_SESSION`: Validates that asset is approved and that `avatar.allowedContexts.includes(session.format)` (rejects with `AVATAR_CONTEXT_DISALLOWED` if format not permitted, and `AVATAR_NOT_APPROVED` if draft).
  - `START_SESSION`: Rejects sessions configured with retired avatars (`AVATAR_RETIRED`) or unapproved avatars (`AVATAR_NOT_APPROVED`).
- Enforced live fan stage draft quarantine in `src/views/SessionView.tsx`:
